## Scope and integrity

Intermediate work uses personal training systems and synthetic or appropriately sanitized data. Technical completion is **not** the same as an approved NEXLEVR submission or certification.

For Task 01, the six observed SSH-related Wazuh alerts represent **deliberate, authorized test activity**. They are not production security incidents.
